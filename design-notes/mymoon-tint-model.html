the mymoon gallery tile — reference model

What color should the Moon photo actually wear?

The mymoon tile washes a color over the real NASA photo with mix-blend-mode: color — originally that overlay was driven only by Sun elevation. A second, independent input belongs in the same wash: the Moon's own altitude, which sets how much atmosphere its light crossed to reach the observer. This page renders the blend live, the same CSS technique the card ships, across both — the exploration that shaped #177 and #178, both now shipped.

How the wash is built

Two color layers stack on the photo, each in mix-blend-mode: color — hue and saturation come from the layer, luminosity (the photo's own lit/dark shape) comes from underneath.

Why the falloff is steep, not linear

airmass ≈ 1 / sin(altitude)
strength = clamp(1 − sin(altitude), 0, 1) ^ 1.5

Airmass — how much atmosphere a sightline crosses — is steep near the horizon and flat above roughly 30°. A linear fade reads as "a bit orange everywhere"; this curve keeps the wash concentrated where extinction actually happens and leaves anything above ~60° essentially bare.

a real limitation, found and fixed (#177)

mix-blend-mode: color takes hue and saturation from the top layer — an achromatic color (no hue, no saturation) passes straight through untouched. The original Night anchor was #000000, which is achromatic, so the sky wash silently no-opped at night instead of darkening the mymoon photo. Fixed by swapping the anchor for a near-black color that keeps Astronomical Twilight's own hue (NIGHT_RGB in viewing-location.ts) — dark enough to still read as night, chromatic enough to actually blend.

The extinction wash added in #178 inherits the lesson: its hue (MOON_EXTINCTION_RGB = rgb(255, 102, 26)) is deliberately saturated so it stays chromatic across its whole strength range, and its strength is carried as the tint layer's own alpha (an rgba() string) rather than a second color to mix by hand.

shipped

Sky wash needed no change in shape — card.ts's .gallery-thumb-tint, painted from skyBackgroundForElevation(sunElevDeg), stayed the base layer; only its night-anchor color changed (#177).

Moon altitude was already computed and unused — getMoonSkyAngles() returns altitudeDeg in viewing-location.ts, previously spent only on the belowHorizon show/hide check. moonExtinctionTint(altitudeDeg) now reads it into a second tint div on both the gallery thumbnail and the full-screen panel (#178).
